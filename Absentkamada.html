Pengaturan Sistem

Validasi Lokasi Kehadiran Guru

Titik sekolah diambil dari pin Google Maps MA Abu Darrin. Guru yang mengisi kehadiran sendiri harus mengaktifkan GPS dan berada dalam radius yang ditetapkan.

Klik “Cek Lokasi Saya Saat Ini” untuk membaca koordinat GPS perangkat.

Saran awal 500 meter. Gunakan nilai lebih besar jika GPS perangkat sering tidak akurat.

Ubah Password Administrator

Password baru minimal 8 karakter. Perubahan diproses melalui fungsi keamanan database.

Administrasi Database

Backup seluruh data aplikasi tanpa Google Sheets.

Sebelum import

Gunakan file hasil “Ekspor Database JSON” dari aplikasi ini. Proses mengirim data guru/akun, siswa, mapel, kelas, penugasan, absensi siswa, kehadiran guru, dan pengaturan ke backend. Ekspor cadangan terbaru terlebih dahulu. Data dengan ID yang sama dapat diperbarui; proses ini tidak otomatis menghapus data yang tidak ada di file.

Migrasi hanya dilakukan untuk memindahkan data dari Apps Script lama ke database realtime. Setelah berhasil, aplikasi menggunakan database realtime.
